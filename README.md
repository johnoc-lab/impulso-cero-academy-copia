# Impulso Cero Academy

Sitio web de Impulso Cero Academy creado con React, TypeScript, Vite, Tailwind CSS y Motion.

## Requisitos
- Node.js 20 o superior
- npm

## Ejecutar en desarrollo
```bash
npm install
npm run dev
```

## Generar versión de producción
```bash
npm run build
npm run preview
```

## Antes de publicar
1. Abre `src/data.ts` y reemplaza `WHATSAPP` por el número oficial en formato internacional, sin `+` ni espacios.
2. Verifica que los datos de sede, horarios, talleres y programas estén actualizados.
3. Los recursos gráficos y vídeos están en `public/`.

La carpeta `dist/` se genera al ejecutar `npm run build`, por eso no se incluye en este paquete de código fuente.
